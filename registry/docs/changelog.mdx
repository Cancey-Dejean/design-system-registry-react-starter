## October 5, 2026

### v1.6.0

- **Docs:** New [Component flows](/flows) page shows how registry items depend on each other. Choose between three layouts: a registry map, lineage lanes, or an install chain that lists everything `shadcn add` pulls in, in order. Search for an item by name to jump to its flow. The install chain shows each component's props: its variants with their options and defaults, plus the props it declares itself. Open **Detailed list** for a table of every prop with its type and default. Hover a node to preview another item's props. **Props** branches each prop into its own node on the canvas and is on by default; turn on **Options** to list every option with its default. Your layout choice is remembered for the browser session.
- **Docs:** Docs pages meant for registry maintainers show a **Maintainers** badge in the sidebar. [Registry](/docs/registry) is marked, since it covers authoring items in this repo rather than installing them. Mark other pages with `audience: maintainers` in their frontmatter.

## September 30, 2026

### v1.5.7

- **Styles:** The type scale in `theme.css` (`text-14`, `text-label`, and the other `--text-*` sizes) is one font-size theme. The docs app `cn` helper treats those classes as sizes, so a text color no longer removes them.
- **Fix:** `Heading` sizes (`text-60`, `text-72`, and the rest of that scale) stay applied next to a tone color.
- **Docs:** [Styles](/docs/styles) documents the type scale and the `cn` registration those `text-*` sizes need. The README covers the same setup.

## September 17, 2026

### v1.5.4

- **Docs:** Updated the Bun install command on [Installation](/docs/installation) and [Styles](/docs/styles) to `bunx shadcn add "@design-system-ui/..."`, which works in new Bun projects.

## August 14, 2026

### v1.5.0

- **Update:** Components that use `class-variance-authority` now keep every `cva()` call in a colocated `<name>.variants.ts` file (`.ts`, not `.tsx`). The component file imports the helper; it does not define CVA inline.
- **Update:** Moved CVA out of component source for `Alert`, `Attachment`, `Badge`, `Bubble`, `Button Group`, `Empty`, `Field`, `Input Group`, `Item`, `Marker`, `Navigation Menu`, `Sidebar`, `Tabs`, and `Toggle`. `Toggle Group` now imports `toggleVariants` from `toggle.variants.ts`.
- **Update:** Renamed `container.variants.tsx` / `container.types.tsx` to `.ts` so the file extension matches the variants convention.
- **Docs:** Documented the Component Variants pattern on the [Registry](/docs/registry) authoring page, with pointers from Agents docs, `AGENTS.md`, and the `shadcn-registry` skill so maintainers and coding agents follow the same layout as `button.variants.ts`.

## August 10, 2026

### v1.4.0

- **Breaking:** Multi-file components now publish nested folder structure instead of flattening basename-only into `ui/`. Nested packages such as `Icons` and `Logos` install under `components/icons/**` and `components/logos/**` (including `icon/`, `icon-set/`, `logo/`, and `logo-set/`).
- **Update:** Same-item relative imports are preserved in installed source so multi-file packages keep working after `shadcn add` (for example `./icon.variants`, `./logo-set/apple`, `../index`).
- **Update:** Added explicit install `target`s for every published `Icons` and `Logos` file; removed unused `icon-set/types.ts` and `logo-set/types.ts` stubs.
- **New:** `Data Table` now publishes sample `payments.tsx` (columns + fixture data) as a registry file, not story-only source.
- **Docs:** Install targets and usage examples updated across registry items (including `Accordion`, `Button`, `Hero`, and many component `_registry.mdx` pages) so install paths match consumers’ `components.json` aliases.
- **Docs:** Component registry preview exports and docs samples tightened for catalog rendering.

## July 19, 2026

### v1.1.0

- **Update:** `Button` variants and sizes now use CSS variables for colors and typography, improving theme support (including dark mode on the primary variant).
- **Update:** Simplified default icon (`svg`) sizing inside buttons.
- **Breaking:** Removed the `link` variant. Use an `as="a"` button (or a link styled separately) instead.
- **Breaking:** Removed the `icon-xs` size. Use `icon-sm`, `icon-md`, or `icon-lg`.
- **Breaking:** Resized icon buttons — `icon-md` is now `size-9` (was `size-10`) and `icon-lg` is now `size-10` (was `size-12`).
