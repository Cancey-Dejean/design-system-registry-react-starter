A date picker built from [Popover](/components/popover) and [Calendar](/components/calendar). See
also the [shadcn/ui Date Picker guide](https://ui.shadcn.com/docs/components/base/date-picker).

```tsx
import {
  DatePicker,
  DatePickerWithRange,
} from "@/components/datepicker/datepicker";

export function Example() {
  return (
    <div className="flex flex-col gap-4">
      <DatePicker />
      <DatePickerWithRange />
    </div>
  );
}
```

Composition:

```
Popover
├── PopoverTrigger
└── PopoverContent
    └── Calendar
```

Use `captionLayout="dropdown"` for date-of-birth style month/year dropdowns. Pair with `fromYear` /
`toYear` (mapped to calendar `startMonth` / `endMonth`) to bound selectable years.
