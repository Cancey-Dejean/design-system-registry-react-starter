Use Section to wrap page content with consistent horizontal padding and responsive vertical spacing.
Set `padding` to control the top and bottom rhythm.

```tsx
import Section from "@/components/section/section";

<Section padding="md">
  <h2>Section title</h2>
  <p>Section content</p>
</Section>;
```
