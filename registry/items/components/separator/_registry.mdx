Use a separator to divide content groups horizontally or vertically.

```tsx
import { Separator } from "@/components/ui/separator";

<div>
  <div>Section one</div>
  <Separator className="my-4" />
  <div>Section two</div>
</div>
```

Pass `orientation="vertical"` for an upright divider.
