Use for toolbar-style on/off controls. Export `toggleVariants` is shared with toggle-group styling.

```tsx
import { IconBold } from "@tabler/icons-react";

import { Toggle } from "@/components/ui/toggle";

<Toggle aria-label="Toggle bold">
  <IconBold />
</Toggle>
```

Variants: `default`, `outline`. Sizes: `default`, `sm`, `lg`. Control with `pressed` /
`onPressedChange` when needed. Built on Base UI Toggle.
